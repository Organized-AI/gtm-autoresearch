# Bundled typography

JetBrains Mono and Inter match the typography at https://talk.organizedai.vip/jev/. Static normal weights are bundled from the public Google Fonts stylesheet, fetched 2026-09-22. Each font is distributed under the accompanying SIL Open Font License. Font files are served locally so the private dashboard makes no font request to Google. Italic heading accents use browser synthesis.

Source stylesheet: https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600;700;800&family=Inter:wght@400;500;600;700&display=swap

Licenses: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono and https://github.com/google/fonts/tree/main/ofl/inter.
